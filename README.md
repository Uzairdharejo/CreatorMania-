# CreatorMania

Viral content research tool for YouTube, TikTok & Instagram creators. Analyze why content blows up and grow faster.

## Tech Stack
- **Frontend**: React / Next.js
- **Backend**: Node.js + Express
- **Database**: MongoDB

## Features
- Analyze viral videos across platforms
- Keyword and trend research
- Content performance metrics

## Getting Started

### 1. Clone repo
```bash
git clone https://github.com/Uzairdharejo/CreatorMania-.git
cd CreatorMania-
